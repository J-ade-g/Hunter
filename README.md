# Hunter · 整活相机

**拍照识梗游戏** —— AI 裁判 + 网络热词 + 离谱判词，越抽象越容易过。

[在线体验](https://hunter-3vwu.onrender.com)

---

## 这是什么？

系统随机给你一个网络热词（如「班味」「发疯」「钝感」），用照片去表现它。AI 裁判会用天马行空的解读判定你是否通关，并给出一段离谱又好笑的判词。你拍得越抽象，AI 越兴奋。

### 判词示例

> "绝了！这个低头的姿势完美诠释了'牛马'——坐姿即正义，打工人的脊梁就是这么弯的！"

---

## 怎么玩

1. 系统随机分配今日任务 —— 一个网络热词
2. **拍照**表现这个词（越创意越好，越抽象越好）
3. AI 裁判判定是否 match，给出评分和离谱判词
4. 查看**排行榜**，跟朋友比谁的抽象力更强

AI 判定规则是「偏向通过」的 —— 只要不是纯黑屏/白屏，AI 总会想办法帮你找到照片和热词之间的联系。

## 技术实现

| 层 | 技术 |
|---|---|
| 前端 | HTML + Tailwind CSS，粗野主义手绘风格 |
| 后端 | Express (Node.js) |
| AI 裁判 | 智谱 GLM-4V-Flash（视觉模型，看图判词） |
| 数据 | Supabase（PostgreSQL，任务库 + 得分记录 + 排行榜） |

### API

- `GET /api/task` — 随机获取一个寻宝任务
- `POST /api/identify` — 提交照片 + 关键词，AI 判定匹配度
- `GET /api/scores` — 最近得分记录
- `GET /api/leaderboard` — 玩家排行榜（含平均分和参赛次数）
- `GET /api/stats` — 全站累计通关次数

### 任务库

预置 50+ 个网络热词任务：享福、牛马、发疯、躺平、班味、松弛感、内耗、搭子、多巴胺、嘴替、破防、摆烂、拿捏、抽象、氛围感、社恐、废物、上头、暴富、佛系、卷、燃、冷、碎、飘、稳……
